# 需求文档

## 1. 应用概述

### 1.1 应用名称
Glimmer Healing（微光心愈）

### 1.2 应用描述
Glimmer Healing是一款从「关注问题」转向「关注优势」的心理健康陪伴与成长移动端App。结合积极心理学理念，提供沉浸式倾诉、趣味互动、专业心理自测与AI深度干预能力。内置智能入口「苍鹭医生」，支持体验版、心愈版与AI工作台版的分级会员订阅及兑换码激活体系，建立每日AI调用积分额度管理机制，并配套管理员后台管理系统进行会员、兑换码及密钥记录的运营管控。

### 1.3 产品定位
- 核心理念：从关注问题转向关注优势
- 核心能力：沉浸式倾诉、心理测评自测、AI智能体深度解析、每日AI积分额度管理、会员与兑换码后台管理
- 视觉风格：App端采用手绘蜡笔涂鸦治愈系风格；管理员后台采用现代卡片式设计（白底大圆角卡片）

---

## 2. 用户与使用场景

### 2.1 目标用户
- 体验版用户（普通用户/会员已过期用户）：体验免费心理测评量表（SCL-90、SDS、MHT）及每日基础AI体验额度的用户
- 心愈版用户：在有效期内解锁全部专业心理测评与进阶心理互动工具，每日享有标准AI调用额度的用户
- AI工作台版（workspace）用户：在有效期内享有苍鹭医生深度咨询、全场景AI深度解析与高额每日AI积分的高阶用户
- 系统管理员：在管理后台查看统计指标、管理会员状态、配置兑换码、查看兑换密钥记录并处理会员延期或退订运维的运营人员

### 2.2 核心使用场景
- 完成手机号与验证码登录后，在测玩区体验免费测评或升级心愈版解锁更多心理测试
- AI工作台版会员或通过兑换码激活权限的用户，进入学苑页面与苍鹭医生进行深度咨询互动
- 在「我的」页面查看当前会员状态、到期时间、今日AI积分消耗进度及权益说明
- 在关系网络图、冰山分析、沙盘游戏室、曼陀罗AI解析、梦境解析器、心灵速写等场景发起AI解读并消耗每日积分（每次交互扣减5点积分）
- 管理员在后台卡片式工作台查看运营指标与套餐分布，管理兑换码，查询用户密钥兑换明细
- 管理员在后台对异常或特定用户执行手动延长会员有效期（快速延期7天/30天/90天/自定义）或取消会员订阅（降级体验版）

### 3.2 功能说明

#### 3.2.1 用户认证模块
1. 登录页面：
  - 视觉呈现：采用手绘蜡笔涂鸦治愈系风格。
  - 输入项：手机号输入框、短信验证码输入框。
  - 交互：点击获取验证码触发60秒倒计时；点击登录校验格式与有效性，校验通过进入主界面；提供注册页面跳转入口。
2. 注册页面：
  - 输入项：手机号输入框、短信验证码输入框、密码设置输入框。
  - 流程：校验通过后创建账号，默认赋予体验版权限（free, level 0）并初始化当日基础AI积分额度。

#### 3.2.2 学苑与智能体模块
1. 苍鹭医生AI智能体页面：
  - 权限要求：仅限处于有效期内的「AI工作台版（workspace）」会员或已使用有效兑换码激活该权限的用户进入。
  - 功能描述：提供多轮自然语言深度心理咨询与干预，每次对话交互接入积分校验与扣减机制（默认单次扣减5点积分）。
2. 权限拦截机制：
  - 未开通或会员已过期的用户点击苍鹭医生时，阻断进入并弹出提示弹窗，明确提示「该功能需AI工作台版权限或通过兑换码激活」，并提供「升级工作台版」与「输入兑换码」操作入口。

#### 3.2.3 测玩与互动工具模块
1. 心理测试专区：
  - 免费测评：SCL-90、SDS、MHT面向所有用户（含体验版及过期用户）开放免费测评与基础报告查看。
  - 心愈版专属测评：包含房树人HTP、自信度测试、MBTI等测评量表。体验版及会员已过期用户点击时弹出心愈版升级/续费提示。
2. 互动工具与AI深度能力：
  - 全场景AI分析接入：在关系网络图（关系洞察）、冰山分析、沙盘游戏室（AI深度解读）、曼陀罗AI解析、梦境解析器、心灵速写（AI生图与解析）、电子OH卡解读等所有发起大模型调用的功能点，均接入统一的AI积分额度校验与扣减逻辑（默认单次扣减5点积分）。
  - 额度前置检查：调用前校验当日剩余积分是否达到单次最低消耗门槛（5点），不足时阻断请求并弹出积分不足提示；调用成功后即时扣减对应积分。

#### 3.2.4 「我的」（心灵档案）模块
1. 会员套餐卡片：展示当前用户的会员等级（体验版/心愈版/AI工作台版）及有效期截止时间（expires_at）。若已过期，状态显示为体验版并标注已到期。
2. 今日AI额度积分卡片：
  - 布局位置：位于「会员套餐」卡片正下方。
  - 核心指标：展示今日AI积分消耗情况，格式为「已用积分 / 总额度积分」（如：15 / 50 积分），配合彩色进度条直观呈现消耗比例。
  - 重置提示：标明「每日24:00自动重置，不累计至次日」。
  - 底部权益说明排版规范：底部说明文字采用多行规整分行排版，避免文本折行拥挤与错位：
    + 第一行（消耗规则）：标注「大模型对话 / 智能体 / AI深度解读 / 心绘生图 每次交互扣减5点积分」；
    + 第二行（额度配额）：标注「体验版 5/日 · 心愈版 50/日 · 工作台版 100/日」。

#### 3.2.5 会员中心与订阅模块
1. 会员套餐页面：展示各等级权益对比表及每日AI额度配额（标明单次AI交互消耗5点积分），提供订阅续费与兑换码入口。
2. 兑换码激活功能：支持输入兑换码，校验成功后立即赋予对应会员身份，更新有效期（expires_at），即时刷新当日AI额度上限，并在后台生成兑换密钥记录。

#### 3.2.6 管理员后台管理系统
1. 界面视觉规范：整体采用现代卡片式布局，界面由白底大圆角卡片构成，分区展示统计与业务管理内容。
2. 统计指标卡与套餐分布卡：
  - 统计指标卡：展示总用户数、当前有效会员数（心愈版/工作台版）、今日AI调用总次数、今日兑换码使用量等关键指标。
  - 套餐分布卡：以卡片形式直观展示各会员等级（体验版、心愈版、AI工作台版）的用户分布数量及占比。
3. 兑换码管理卡：
  - 支持生成指定套餐类型（心愈版/AI工作台版）、有效天数、有效期的兑换码。
  - 提供兑换码列表展示，包含密钥Code、所属套餐、有效天数、生成时间、使用状态（未使用/已使用/已作废）及作废操作。
4. 用户兑换密钥记录卡：
  - 记录并展示所有通过兑换码激活的明细流水，避免卡单与审计缺失。
  - 字段包含：兑换人（用户手机号/用户ID）、兑换时间、密钥Code、套餐类型、天数、变更前到期时间、变更后到期时间。
  - 提供按手机号、密钥Code查询筛选能力。
5. 会员管理卡：
  - 会员列表：展示用户ID、手机号、当前会员等级、当前到期时间（expires_at）、当日AI已用/总额度、注册时间。
  - 手动延期操作：支持管理员针对指定用户执行手动延期，提供快捷延期选项（7天、30天、90天）及自定义输入天数，确认后即时延长会员到期时间并记录操作流水。
  - 取消订阅操作：支持管理员手动取消用户会员订阅，确认后立即将用户会员等级降级为体验版（free, level 0），并将有效期重置，当日AI总额度同步降为体验版标准。

## 4. 业务规则与核心逻辑

### 4.1 会员分级与到期校验审计规则
1. 会员等级定义：
  - 体验版（free, level 0）：可免费使用SCL-90、SDS、MHT量表；享有每日5个AI积分额度（可体验1次AI交互）；不可使用心愈版专属测评及苍鹭医生。
  - 心愈版（level 1）：在有效期内享有全套心理测评（含房树人HTP、自信度、MBTI等）及互动工具自主创作权限；享有每日50个AI积分额度（支持10次AI交互）。
  - AI工作台版（workspace, level 2）：在有效期内享有心愈版全部权益及苍鹭医生AI咨询、全场景AI深度解析大模型能力；享有每日100个AI积分额度（支持20次AI交互）。
2. 会员到期（expires_at）审计逻辑：
  - 系统在用户启动App、进入专属模块、发起AI请求及定时轮询时校验会员截止时间 `expires_at`。
  - 当 `当前时间 > expires_at` 时，会员权限立即失效，用户等级即刻降级为体验版（free, level 0）。
  - 到期降级后，心愈版与AI工作台版的全部专属功能（如苍鹭医生、房树人HTP、MBTI等）立即执行严格权限拦截，提示用户续费。
  - 到期降级后，当日AI总额度即刻调整为体验版标准（5积分/日），若当日已消耗积分已达到或超过5积分（即已无足额5积分），则立即限制当日后续AI调用。

### 4.2 全场景AI积分额度与消耗规则
1. 额度标准：
  - 体验版（含已过期降级用户）：5 积分/日
  - 心愈版（有效期内）：50 积分/日
  - AI工作台版（有效期内）：100 积分/日
2. 单次消耗与扣减机制：
  - 单次消耗基准：默认单次对话/AI交互扣减5点积分。
  - 覆盖范围：包含苍鹭医生对话、关系网络图（关系洞察）、冰山理论分析、3D沙盘深度解读、曼陀罗AI解析、梦境解析器、心绘小屋生图/速写解析、电子OH卡AI解读等所有大模型调用场景。
  - 前置校验与执行流程：用户触发AI功能时，系统首先执行前置额度检查，校验当前剩余积分是否大于等于5点；若剩余积分充足（>=5）则发起请求并在返回成功后扣减5点积分；若请求失败或超时则不扣减积分。
  - 耗尽阻断：当可用积分不足单次最低消耗（<5点）时，阻断大模型请求，弹出提示「当前剩余AI积分不足5点，无法发起分析/对话，每日24:00自动重置」，并引导升级/续费套餐或次日使用。
3. 清零与重置规则：
  - 积分每日有效，当日未用完积分在当日24:00自动清零，不跨日累计。
  - 每日00:00根据用户实时有效会员等级重置发放当日初始满额积分。

### 4.3 兑换码激活与后台管理规则
1. 兑换码激活流转规则：
  - 用户输入有效兑换码后，系统校验其有效性及使用状态。
  - 若用户当前处于有效会员期且兑换同等级会员，则在当前 `expires_at` 基础上顺延相应天数；若兑换高等级会员，则等级即刻升级并在当前时间基础上增加对应天数。
  - 激活成功后，系统即时生成一条用户兑换密钥记录，写入兑换人、兑换时间、密钥Code、套餐类型、天数及变更后到期时间，兑换码状态标记为已使用。
2. 管理员手动延期与取消订阅规则：
  - 手动延期：管理员在后台选择快捷天数（7/30/90天）或输入自定义天数后，若用户当前为体验版，则需指定会员等级并在当前时间上顺延天数；若为有效会员，则直接在现有 `expires_at` 基础上顺延指定天数。变更即时生效，当日AI额度上限同步刷新。
  - 取消订阅（降级体验版）：管理员在后台确认取消后，用户会员等级立即变更为体验版（free, level 0），`expires_at` 置为失效状态，专属功能即时拦截，当日AI总额度降为5积分/日。

## 5. 异常与边界情况

| 场景 | 异常情况 | 处理方式 |
|------|----------|----------|
| 会员到期 | 用户在使用过程中会员到达截止时间 `expires_at` | 立即将权限置为体验版（free, level 0），阻断专属功能进入，额度上限降为5积分/日并提示会员已到期 |
| AI额度不足 | 苍鹭医生对话/关系洞察/冰山分析/曼陀罗/沙盘等AI功能调用时剩余积分不足5点 | 阻断AI请求，弹出提示「当前剩余AI积分不足5点，无法发起本次交互，每日24:00自动重置」，并引导升级/续费 |
| 权限拦截 | 体验版或过期用户访问房树人HTP、MBTI或苍鹭医生 | 阻断进入，弹出对应权益说明弹窗，引导开通/续费或输入兑换码 |
| 兑换码激活 | 输入无效、已过期或已被使用的兑换码 | 弹出提示「兑换码无效或已被使用，请核对后重试」，不变更用户权限且不产生兑换流水 |
| 兑换卡单防范 | 网络超时导致兑换状态未即时回显 | 后端事务保证兑换码核销与密钥记录写入原子性，用户或管理员可通过兑换记录核对恢复 |
| 后台取消订阅 | 用户正在使用专属功能时被管理员后台取消订阅 | 用户下一次交互或页面切换时校验失效，弹出权益失效提示并返回体验版状态 |
| 服务异常 | 大模型接口调用失败或返回超时 | 弹出提示「分析生成失败，请稍后重试」，系统回滚本次扣减的5点AI积分 |

## 6. 验收标准

1. 管理员进入后台系统，界面呈现白底大圆角的现代卡片式布局，统计指标卡与套餐分布卡数据展示准确。
2. 用户在App端输入有效兑换码激活后，后台兑换密钥记录卡片即时新增一条包含兑换人、兑换时间、密钥Code、套餐类型、天数、变更后到期时间的完整记录。
3. 管理员在后台会员管理卡片中选择指定用户，可通过快捷延期（7天/30天/90天）或自定义天数成功延长用户的 `expires_at`，用户端即时刷新有效时间与AI配额。
4. 管理员在后台对有效会员执行取消订阅操作后，该用户等级即刻降级为体验版，App端专属功能被拦截且当日AI额度调整为体验版标准。
5. 用户在苍鹭医生、关系洞察、冰山分析、3D沙盘深度解读等任意AI场景发起调用时，每次成功交互均准确扣减5点AI积分；剩余不足5点时前置拦截。
6. 用户进入App「我的」页面，今日AI额度卡片底部规整显示扣减规则及各等级配额规则，排版清晰无错位。
